# 트러블슈팅

실제로 발생하고 재현한 오류만 기록한다. 예상 가능한 오류를 해결한 것처럼 작성하지 않는다.

## 현재 상태

사용자 입력 모드, `python3 main.py` JSON 최종 일괄 분석과 크기별 성능 출력을 확인했으며, 현재까지 재현된 프로그램 실행 오류는 없다.

JSON 분석의 FAIL 3건은 Cross/X 동점에 따른 `UNDECIDED`와 expected의 불일치로 발생한 의도된 판정 결과이므로 실행 오류로 기록하지 않는다. 잘못된 사용자 입력도 안내 후 같은 행을 다시 받는 정상 오류 처리 흐름으로 확인됐다.
