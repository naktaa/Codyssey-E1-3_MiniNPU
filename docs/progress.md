# 진행 상태

## 현재 단계

- 단계: 1. 핵심 데이터와 MAC 연산
- 기준 날짜: 2026-08-06
- 작업 시작 시 브랜치: `main`
- 작업 시작 시 저장소 상태: 변경사항 없음, `origin/main`과 동기화
- 구현 상태: 핵심 MAC·epsilon 판정 코드 작성 완료
- 실행 검증: 사용자 검증 대기
- 증거 상태: 미확보

## 완료 작업

- 미션 목적과 필수 제출물 정리
- 기능·데이터·성능·문서 요구사항 분리
- 요구사항 ID와 추적표 작성
- 추천 프로젝트 구조 작성
- 단계별 구현·검증·커밋 계획 작성
- 예상 증거 파일명 작성
- 모호한 조건과 제출 차단 위험 정리
- 초기 저장소 문서 생성
- `data.json` 실제 구조 확인
- 정사각형 숫자 행렬 검증 구현
- 이중 반복문 MAC 연산 구현
- epsilon 기반 `Cross`·`X`·`UNDECIDED` 판정 구현
- 유한한 정수·실수 입력 검증 구현
- 유닛 테스트를 작성·실행하지 않는 사용자 작업 방침 반영

## 확인된 입력과 환경

- 저장소 루트에 실제 `data.json` 존재
- 필터 크기: 5×5, 13×13, 25×25
- 패턴: 크기별 2개, 총 6개
- Python 확인 버전: 3.12.13
- 작업 시작 시 브랜치: `main`

## 확인이 필요한 입력

- 평가에서 요구하는 Git 브랜치·병합 조건

## 현재 문제

- `main.py`가 없어 콘솔 애플리케이션은 아직 실행할 수 없음
- 핵심 로직은 사용자가 직접 검증하기 전이므로 PASS/FAIL을 기록할 수 없음
- 사용자 입력, JSON 분석, 결과 요약과 성능 측정은 아직 미구현

## 다음 권장 작업 하나

**사용자 직접 단계 1 수동 검증**

확인 기준:

- Cross 예시 점수가 각각 5와 1로 계산됨
- 정수와 실수 행렬의 MAC 점수가 계산됨
- 비정사각형 또는 크기 불일치 행렬에 `ValueError`가 발생함
- 점수 차이가 epsilon 미만이면 `UNDECIDED`가 반환됨

검증 결과를 확인한 다음 단계 2 사용자 입력 모드의 구현 방향을 설명하고 승인을 받는다.

## 보너스 상태

- 1차원 배열 최적화: 진행하지 않음
- 패턴 생성기: 진행하지 않음
