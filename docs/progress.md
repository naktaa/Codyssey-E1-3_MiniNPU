- 패턴과 필터의 정사각형·크기 일치 검증 구현

- 메뉴 2번에 JSON 로드 및 정규화 모드 연결
- 실제 JSON 필터 크기 5·13·25와 패턴 6건 로드 확인
- expected Cross/X 정규화와 대응 필터 연결 확인
- 정상 케이스 6건, 구조 오류 0건 확인
- 실제 결과를 `evidence/json-load.md`로 기록
- JSON 각 케이스의 Cross/X MAC 점수와 epsilon 판정 연결
- actual과 expected 비교를 통한 PASS/FAIL 구현
- 데이터·계산 오류를 케이스 FAIL로 기록하고 다음 케이스 계속 처리
- 전체 케이스·통과·실패 수와 epsilon 출력 구현
- 실패 케이스 식별자와 직접 원인 목록 출력 구현
- 결과 출력 책임을 `src/report.py`로 분리
- 실제 JSON 분석에서 6건 중 PASS 3건, FAIL 3건 확인
- 세 동점 케이스가 UNDECIDED로 판정되고 expected 불일치로 FAIL 처리됨을 확인
- 통과 3 + 실패 3 = 전체 6 집계 확인
- 실제 결과를 `evidence/json-analysis.md`로 기록
- 3×3 코드 내부 기준 행렬과 JSON 크기별 첫 정상 케이스를 측정 입력으로 선택
- 네 크기의 `calculate_mac()`을 각각 1,000회 측정하고 평균 계산
- 평균 시간, N² 연산 수, 반복 횟수와 입력 출처를 표로 출력
- 측정 대상·포함 시간·제외 시간과 O(N²) 근거 출력
- 성능 계산을 `src/performance.py`로 분리
- 실제 평균 시간 3×3 `0.018819`, 5×5 `0.040140`, 13×13 `0.222042`, 25×25 `0.773164` ms 확인
- N² 연산 수 9·25·169·625와 모든 크기 1,000회 반복 확인
- 13×13 대비 25×25의 N² 약 3.70배, 시간 약 3.48배 증가 확인
- 실제 결과를 `evidence/performance.md`로 기록
