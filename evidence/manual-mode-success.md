# FUNC-008 사용자 입력 모드 X 판정 실행 로그

## 실행 정보

- 실행일: 2026-08-06
- 실행 주체: 사용자
- 실행 명령: `py`
- 실행 목적: 3×3 필터와 패턴 입력 후 Cross/X 점수, 판정과 평균 MAC 시간 확인
- 개인정보 보호: 터미널 프롬프트의 계정명과 장치명은 기록에서 제거함

## 입력 데이터

### 필터 A (Cross)

```text
0 1 0
1 2 1
0 1 0
```

### 필터 B (X)

```text
1 0 1
0 2 0
1 0 1
```

### 패턴

```text
1 0 1
1 1 0
1 0 1
```

## 실제 출력

```text
=== Mini NPU Simulator ===
1. 3x3 사용자 입력 모드
2. data.json 분석 모드 (구현 예정)
3. 종료
모드를 선택하세요: 1

[3x3 사용자 입력 모드]

필터 A (Cross)를 입력하세요. 한 행에 숫자 3개를 공백으로 구분합니다.
필터 A (Cross) 1행: 0 1 0
필터 A (Cross) 2행: 1 2 1
필터 A (Cross) 3행: 0 1 0

필터 B (X)를 입력하세요. 한 행에 숫자 3개를 공백으로 구분합니다.
필터 B (X) 1행: 1 0 1
필터 B (X) 2행: 0 2 0
필터 B (X) 3행: 1 0 1

패턴를 입력하세요. 한 행에 숫자 3개를 공백으로 구분합니다.
패턴 1행: 1 0 1
패턴 2행: 1 1 0
패턴 3행: 1 0 1

[판정 결과]
Cross 점수: 3.000000
X 점수: 6.000000
판정: X

[3x3 MAC 성능]
평균 시간: 0.018066 ms
측정 대상: 패턴과 필터 A (Cross)의 calculate_mac() 1회
반복 횟수: 1000회
```

## 확인 결과

| 확인 항목 | 실제 결과 | 상태 |
|---|---|---|
| 사용자 입력 모드 진입 | 메뉴 1 선택 후 3×3 모드 진입 | 확인 |
| 필터 A 입력 | 3행 입력 완료 | 확인 |
| 필터 B 입력 | 3행 입력 완료 | 확인 |
| 패턴 입력 | 3행 입력 완료 | 확인 |
| Cross 점수 | `3.000000` | 확인 |
| X 점수 | `6.000000` | 확인 |
| 최종 판정 | `X` | 확인 |
| 성능 측정 대상 | `calculate_mac()` 1회 | 확인 |
| 반복 횟수 | 1,000회 | 확인 |
| 평균 시간 | `0.018066 ms` | 확인 |

입력값을 위치별로 계산하면 Cross 점수는 3, X 점수는 6이므로 실제 `X` 판정과 일치한다.

## 미검증 항목

- 열 개수 오류 후 같은 행 재입력
- 숫자 형식 오류 후 같은 행 재입력
- NaN과 무한대 입력 후 같은 행 재입력
- epsilon 범위 안의 동점에 대한 `UNDECIDED` 출력

## 후속 수정

이 로그에서 확인된 `패턴를 입력하세요` 문구는 이후 `패턴 행렬을 입력하세요`로 수정했다. 해당 문구 수정 후 실행 결과는 아직 검증하지 않았다.
