# 10회 MAC 평균·표준편차 실행 로그

## 실행 정보

- 실행일: 2026-08-11
- 실행 주체: 사용자
- 실행 명령: `py`
- 실행 모드: `data.json` 일괄 분석
- 실행 목적: 10회 독립 측정의 평균·표준편차, 한글 성능 표와 최종 JSON 집계 확인
- 개인정보 보호: 터미널 프롬프트의 계정명과 장치명은 기록에서 제외함

## 실행 환경

- Python: 기존 사용자 확인 버전 3.12.13
- 운영체제: macOS Sequoia 15.7.4
- 프로세서: 3.1GHz 6코어 Intel Core i5
- 그래픽: Radeon Pro 575X 4GB
- 메모리: 32GB 2667MHz DDR4
- 환경 캡처: [mac-status.png](mac-status.png)
- 일련번호: 캡처에서 가림 처리됨

## 확인 결과

- 필수 크기 3×3·5×5·13×13·25×25가 모두 출력됨
- 2차원과 1차원 모두 크기별 10회 측정 확인
- 평균 시간과 모집단 표준편차 출력 확인
- 한글 열 이름과 ms·N² 단위 출력 확인
- 파일 읽기·입력·출력과 1차원 변환이 MAC 측정 구간에 포함되지 않는 코드 구조를 정적으로 확인
- 13×13에서 25×25로 증가할 때 N²는 약 3.70배, 2차원 평균 시간은 약 3.51배 증가
- 이번 실행에서는 네 크기 모두 1차원 평균 시간이 2차원보다 짧게 측정됨
- 전체 결과 요약이 두 성능 표 뒤에 출력됨
