# 생성 필터의 성능 분석 병합 로그

## 실행 정보

- 실행일: 2026-08-13
- 실행 주체: 사용자
- 실행 방식: 같은 프로그램 실행에서 메뉴 3으로 7×7 필터를 생성한 뒤 메뉴 2 실행
- 개인정보 보호: 터미널 프롬프트의 계정명과 장치명은 기록에서 제외함

## 실행 목적

- 7×7 Cross/X 필터의 생성 모양 확인
- 실행 중 생성 필터가 모드 2 성능 분석에 재사용되는지 확인
- JSON 필터 크기와 새 생성 크기가 오름차순으로 출력되는지 확인

## 확인 결과

- Cross는 중앙 행과 중앙 열이 1인 7×7 필터로 생성됨
- X는 양쪽 대각선이 1인 7×7 필터로 생성됨
- 생성된 7×7 필터가 같은 실행의 모드 2 성능 입력으로 재사용됨
- 7×7 결과가 5×5와 13×13 사이에 출력됨
- 2차원·1차원 성능표 모두 각 크기를 한 번씩 출력함
- 생성 필터가 추가되어도 JSON 판정 결과는 전체 6건, 통과 3건, 실패 3건으로 유지됨

## 미검증 항목

- JSON에 이미 존재하는 5×5 필터를 실행 중 생성했을 때 성능표의 5×5가 중복되지 않는지
