- 실행 모드: `data.json` 일괄 분석
- 실행 목적: 최종 정상 판정 결과와 크기별 MAC 성능 재확인

통과 3건과 실패 3건의 합이 전체 6건과 일치한다.

## 케이스별 결과

| 케이스 | Cross 점수 | X 점수 | 판정 | expected | 결과 |
|---|---:|---:|---|---|---|
| `size_5_1` | 0.900000 | 0.900000 | UNDECIDED | X | FAIL |
| `size_5_2` | 8.900000 | 0.100000 | Cross | Cross | PASS |
| `size_13_1` | 0.300000 | 14.700000 | X | X | PASS |
| `size_13_2` | 7.500000 | 7.500000 | UNDECIDED | Cross | FAIL |
| `size_25_1` | 4.900000 | 4.900000 | UNDECIDED | X | FAIL |
| `size_25_2` | 52.900000 | 0.100000 | Cross | Cross | PASS |

세 실패는 모두 Cross와 X 점수가 같아 `UNDECIDED`로 판정됐고, expected `Cross` 또는 `X`와 일치하지 않아 발생했다. 구조·계산 오류가 아니라 epsilon 동점 정책에 따른 의도된 결과다.

## 크기별 성능

| 크기 | 평균 시간(ms) | N² 연산 수 | 반복 횟수 | 입력 출처 |
|---|---:|---:|---:|---|
| 3×3 | 0.019228 | 9 | 1,000 | 코드 내부 기준 행렬 |
| 5×5 | 0.040938 | 25 | 1,000 | `data.json size_5_1` |
| 13×13 | 0.230900 | 169 | 1,000 | `data.json size_13_1` |
| 25×25 | 0.807215 | 625 | 1,000 | `data.json size_25_1` |

13×13에서 25×25로 증가할 때 N² 연산 수는 약 3.70배, 평균 시간은 약 3.50배 증가했다. 모든 위치를 이중 반복하는 O(N²) 구조와 실제 측정 경향이 일치한다.

## 측정 조건

- 측정 대상: 패턴과 Cross 필터의 `calculate_mac()` 1회
- 포함 시간: 행렬 검증과 이중 반복문 MAC
- 제외 시간: `data.json` 읽기와 콘솔 출력
- 반복 횟수: 각 크기 1,000회

- `python3 main.py`의 JSON 일괄 분석 정상 실행 확인
- 전체 6건의 판정과 합계 확인
- epsilon 동점 정책에 따른 FAIL 3건 확인
