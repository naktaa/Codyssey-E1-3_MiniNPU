# 단순화 후 필수 실행 및 10회 MAC 성능 로그

## 실행 정보

- 실행일: 2026-08-13
- 실행 주체: 사용자
- 재현 명령: `python3 main.py`
- 성능 측정: 워밍업 10회 제외 후 개별 MAC 호출 10회
- 성능 입력: 크기별 Cross/X 필터 쌍
- 개인정보 보호: 터미널 프롬프트의 계정명과 장치명은 기록에서 제외함

## 실행 목적

- 모드 1의 직접 입력 판정과 공통 `MAC 성능` 표 확인
- 모드 2의 JSON 6건 판정과 전체 집계 확인
- 3×3·5×5·13×13·25×25의 2차원·1차원 순수 MAC 10회 성능 확인
- 판정 결과 뒤에 성능표가 마지막으로 출력되는 순서 확인

## 모드 1 입력

### 필터 A (Cross)

```text
0 1 0
1 1 1
0 1 0
```

### 필터 B (X)

```text
1 0 1
0 1 0
1 0 1
```

### 패턴

```text
1 1 1
0 1 0
1 0 1
```

## 확인 결과

- 모드 1의 점수는 Cross `2`, X `5`이며 판정은 X임
- 모드 1과 모드 2가 같은 열 구성의 성능표를 출력함
- 모드 2는 전체 6건, 통과 3건, 실패 3건으로 집계됨
- 네 필수 크기가 각각 한 번씩 출력됨
- 2차원·1차원 모두 반복 횟수 10이 표시됨
- 네 크기 모두 이번 실행에서 1차원 평균 시간이 2차원보다 낮음
- 판정 요약 뒤에 2차원·1차원 성능표가 마지막으로 출력됨

## 미검증 항목

- JSON과 같은 크기의 생성 필터가 성능표에 중복되지 않는지
- 최신 코드에서 잘못된 사용자 입력의 행 단위 재입력 흐름

JSON에 없는 7×7 생성 필터의 추가·재사용과 오름차순 출력은
[`generated-filter-merge.md`](generated-filter-merge.md)에서 확인했다.
