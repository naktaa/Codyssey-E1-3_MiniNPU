# 모드 1 N×N 자동 생성·저장 필터 사용 확인

## 실행 정보

- 실행일: 2026-08-10
- 실행 주체: 사용자
- 실행 명령: `py`
- 실행 목적: 모드 1 하위 2번에서 3×3 필터 자동 생성, 패턴 판정과 실행 중 저장 필터 사용 확인
- 개인정보 보호: 터미널 프롬프트의 계정명과 장치명은 기록하지 않음

## 자동 생성 실행

프로그램 실행 직후 모드 1의 `크기 선택 후 저장 또는 자동 생성 필터 사용`을 선택하고 크기 3을 입력했다. `data.json`에는 3×3 필터가 없으므로 다음 안내가 출력됐다.

```text
3x3 저장 필터가 없어 자동으로 생성합니다.
```

입력한 패턴은 다음과 같다.

```text
0 1 0
1 1 0
0 1 0
```

실제 판정과 성능 출력은 다음과 같다.

```text
[판정 결과]
Cross 점수: 4.000000
X 점수: 1.000000
판정: Cross

[3x3 MAC 성능]
평균 시간: 0.018306 ms
측정 대상: 패턴과 Cross 필터의 calculate_mac() 1회
반복 횟수: 1000회
```

출력 후 메인 메뉴로 복귀했다. 입력 패턴은 자동 생성 Cross 필터의 활성 위치 네 곳과 일치하고 X 필터와는 가운데 한 곳만 일치하므로 Cross 4, X 1과 실제 출력이 일치한다.

## 저장 필터 사용 확인

같은 프로그램 실행에서 다시 모드 1의 하위 2번과 크기 3을 선택했을 때 다음 안내가 출력되는 것을 사용자가 확인했다.

```text
3x3 저장 필터를 사용합니다.
```

두 번째 실행의 패턴, 점수와 성능값 원문은 전달받지 않았으므로 기록하지 않는다. 위 안내를 근거로 첫 실행에서 자동 생성한 필터가 같은 프로그램 실행 중 저장소에 유지되고 모드 1에서 다시 선택되는 흐름을 확인했다.

## 확인 결과

- `data.json`에 없는 3×3 필터의 자동 생성 확인
- 자동 생성 Cross/X 필터를 사용한 MAC 점수와 판정 확인
- 모드 1의 단일 Cross MAC 1,000회 평균 시간 출력 확인
- 모드 완료 후 메인 메뉴 복귀 확인
- 같은 실행에서 3×3 저장 필터 선택 안내 확인

## 별도 실행하지 않은 추가 항목

- 짝수 또는 3 미만 크기 입력의 재입력 안내
- 생성한 7×7이 모드 2 성능 표의 5×5와 13×13 사이에 표시되는지 확인

두 항목은 미션 원문의 보너스 완료 조건에 필요한 별도 산출물이 아니므로 이번 검증 범위에서 제외했다.
