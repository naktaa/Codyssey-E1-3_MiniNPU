# 잘못된 행 입력 재시도 로그

## 실행 정보

- 실행일: 2026-08-06
- 실행 주체: 사용자
- 실행 목적: 3×3 행렬에서 열 개수와 숫자 형식이 잘못된 경우 해당 행만 다시 입력하는지 확인
- 로그 범위: 필터 A(Cross) 입력 구간

## 실제 입력과 출력

```text
필터 A (Cross) 행렬을 입력하세요. 한 행에 숫자 3개를 공백으로 구분합니다.
필터 A (Cross) 1행: 1 0 1
필터 A (Cross) 2행: 1 1 0 1
입력 오류: 숫자를 정확히 3개 입력해야 합니다. 현재 행을 다시 입력하세요.
필터 A (Cross) 2행: 0 1 0
필터 A (Cross) 3행: q 0 1
입력 오류: 모든 값은 숫자여야 합니다. 현재 행을 다시 입력하세요.
필터 A (Cross) 3행: 1 0 1
```

## 확인 결과

| 확인 항목 | 실제 동작 | 상태 |
|---|---|---|
| 정상 1행 입력 | 다음 행인 2행으로 이동 | 확인 |
| 열 개수 오류 | 숫자 4개 입력 시 오류 메시지 출력 | 확인 |
| 열 개수 오류 후 재입력 | 2행을 다시 요청 | 확인 |
| 정상 2행 재입력 | 다음 행인 3행으로 이동 | 확인 |
| 숫자 형식 오류 | `q` 입력 시 오류 메시지 출력 | 확인 |
| 숫자 형식 오류 후 재입력 | 3행을 다시 요청 | 확인 |
| 정상 3행 재입력 | 입력을 정상적으로 받음 | 확인 |

오류가 발생한 행만 다시 요청했으며 이미 정상적으로 입력한 이전 행은 다시 요청하지 않았다.

## 미검증 확장 입력

- `NaN` 입력
- `inf`, `-inf` 입력

NaN과 무한대 거부는 추가 방어 로직이며, 필수 열 개수·숫자 형식 재입력 요구사항은 이번 로그로 확인했다.
