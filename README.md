# Mini NPU Simulator

E1-3 미션용 Python 콘솔 애플리케이션 저장소입니다.

> 현재 상태: 단계 2 사용자 입력 모드 정상 실행·오류 재입력 확인 / 단계 3 준비

## 실행 환경

- Python 3.8 이상
- 기본 검증 환경: macOS, zsh
- 외부 라이브러리 사용 금지
- 표준 라이브러리만 사용

## 실행 방법

저장소 루트에서 실행합니다.

```zsh
python3 main.py
```

현재 메뉴에는 다음 모드가 표시됩니다.

1. 사용자 입력(3×3): 정상 입력, X 판정과 오류 행 재입력 확인
2. `data.json` 분석: 구현 예정
3. 프로그램 종료

`data.json`은 저장소 루트에 두는 것을 기본으로 합니다.

## 구현 요약

현재 구현된 핵심 로직은 다음과 같습니다.

- 숫자로 구성된 비어 있지 않은 n×n 행렬인지 검증합니다.
- 패턴과 필터의 크기가 같은지 확인합니다.
- 같은 위치의 값을 이중 반복문으로 곱하고 누적하여 MAC 점수를 구합니다.
- 정수와 실수를 `float` 점수로 계산합니다.
- 두 점수 차가 기본 epsilon `1e-9`보다 작으면 `UNDECIDED`로 판정합니다.
- 그 외에는 내부 표준 라벨 `Cross`, `X` 중 하나로 판정합니다.
- 무한대, NaN, bool과 숫자가 아닌 값은 명시적인 오류로 처리합니다.
- 필터 A(Cross), 필터 B(X)와 패턴을 각각 3×3 행렬로 입력받습니다.
- 열 개수나 숫자 형식이 잘못된 행만 다시 입력받습니다.
- 두 MAC 점수와 Cross/X/판정 불가 결과를 출력합니다.
- 패턴과 필터 A 사이의 `calculate_mac()` 한 번을 1,000회 반복 측정해 평균 시간을 출력합니다.

JSON 로드·정규화, 일괄 결과 보고와 전체 크기별 성능 분석은 이후 단계에서 구현합니다.

## 검증 예정 항목

- 3×3 Cross/X 예시 점수 확인
- A/B 판정과 epsilon 동점 판정 확인
- 행 개수·열 개수·숫자 파싱 오류 후 재입력 확인
- 실제 `data.json` 모든 케이스 분석
- 필터·패턴 크기 불일치 케이스 단위 FAIL 확인
- 총 테스트·통과·실패 합계 확인
- 3×3·5×5·13×13·25×25 성능 표 확인
- 사용자 수동 실행 결과와 요구사항 일치 확인

추가 실행 결과와 PASS/FAIL은 사용자의 실제 검증 결과를 받은 뒤 기록합니다.

## 현재 확보된 3×3 실행 결과

사용자가 필터 A(Cross), 필터 B(X)와 패턴을 직접 입력한 결과는 다음과 같습니다.

| 항목 | 실제 결과 |
|---|---:|
| Cross 점수 | `3.000000` |
| X 점수 | `6.000000` |
| 판정 | `X` |
| 3×3 평균 MAC 시간 | `0.018066 ms` |
| 반복 횟수 | 1,000회 |
| 측정 대상 | 패턴과 필터 A의 `calculate_mac()` 1회 |

점수와 판정, 성능 출력을 확인했다. 상세 로그는 [FUNC-008 사용자 입력 모드 X 판정](evidence/FUNC-008-manual-mode-x.md)에 기록했다.

잘못된 열 개수와 문자 입력 후 오류가 발생한 행만 다시 요청하는 동작도 확인했다. 상세 로그는 [FUNC-007 잘못된 행 입력 재시도](evidence/FUNC-007-invalid-input.md)에 기록했다.
